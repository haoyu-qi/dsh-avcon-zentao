# @deepseek-ai/dsh-client-ui-zentao-notifications

[English](README.md) | 中文

浏览器端禅道个人工作插件。它注册一个附加的 `shell.overlay` 配置项，禅道入口默认位于顶部应用控件下方的对话区域内。入口可在对话区域内拖动；点击仍会打开面板，面板会根据入口位置切换水平与垂直对齐方向并保持可见。禅道图标带有文字辅助的状态指示，可显示未连接、连接或拉取中、已连接和连接异常。面板接收服务器地址、个人账户和密码，再通过通用 Connection RPC 通道请求登录，并从 Host 网关拉取分配给该账户的任务和 Bug。

登录后，组件在自身生命周期内保存返回的账户信息与任务／Bug 快照。用户可以切换任务和 Bug 列表、立即拉取，或选择 1、5、15、30 分钟的自动拉取间隔。可选的“记住服务器和账号”会在下次访问时从浏览器本地存储恢复这两个字段。登录成功后，密码会从 React 状态中清除，且始终不会写入浏览器存储。按 Escape 或在面板外点击会关闭面板。

任务和 Bug 卡片支持拖拽，并提供“打开原始页面”链接。将卡片拖到对话输入框后，系统会在当前选区插入紧凑、可编辑的 Markdown 引用。链接标题包含工作项编号、标题与禅道原始链接，随后列出状态、优先级、截止／更新时间，并明确要求在处理前使用禅道 CLI 读取最新详情和上下文。

## 模型体验

无，因为拖拽只会生成普通输入框草稿；只有用户提交后，既有对话路径才会控制模型可见性与会话日志。

#### KV Cache 影响

无；本包既不组装也不发送提供方请求。

## 已知限制与暂缓事项

- **登录状态仅在进程生命周期内有效** —— Host 重启后仍需通过面板重新登录；浏览器偏好仅恢复服务器和账号字段，官方 CLI 独立拥有 Token。
- **受限拉取** —— 每次刷新最多显示 100 条已分配任务和 100 条已分配 Bug；Bug 发现覆盖可访问产品的前 100 条。
- **禅道只读投影** —— 面板可以列出个人任务和 Bug，并在对话中引用它们，但不能在禅道中编辑、解决或关闭它们。
